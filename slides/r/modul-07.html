Video 7.1
Anatomi prompt analisis

Prompt yang buruk

Analisis data ini pakai ANOVA.
  • Tidak ada desain penelitian
  • Tidak ada tujuan
  • Pilihan uji sudah dikunci sebelum dipertimbangkan

AI akan menjalankan ANOVA dengan patuh, walau datanya hitungan dengan plot bersarang.

Lima unsur prompt analisis

Unsur Isi Contoh
Sistem OS, versi R, paket Mac Apple M2, R 4.x, tidyverse, glmmTMB
Data Struktur dan tipe kolom Hasil glimpse()
Desain Unit, ulangan, bersarang/berulang 8 stasiun × 6 plot
Tujuan Pertanyaan penelitian, bukan nama uji Apakah semai berbeda antarzona?
Batasan Yang tidak boleh diubah, format Jangan membuang baris; jelaskan asumsi

Templat

SISTEM: Saya memakai [Mac/Windows ...], R [versi], paket [...].
DATA: [hasil glimpse(), tanpa identitas]. Arti kolom: [...].
DESAIN: [unit, jumlah ulangan, struktur bersarang atau berulang].
TUJUAN: [pertanyaan penelitian].
BATASAN: jangan membuang atau mengubah data tanpa menjelaskan; pakai tidyverse;
jelaskan asumsi dan cara memeriksanya; sebutkan bila ada lebih dari satu
pendekatan yang wajar.

Prompt yang lebih baik tidak menjamin jawaban benar, tetapi mempersempit ruang kesalahan.

Tujuh kesalahan khas AI

1. Argumen yang tidak ada

x <- c(3, 5, NA, 7)
mean(x, remove_na = TRUE)   # NA, tanpa error: argumen ditelan "..." lalu diabaikan
mean(x, na.rm = TRUE)       # 5

Cara memeriksa: cocokkan setiap argumen dengan halaman Help (F1).

2–7. Enam kesalahan lain

No Jenis Contoh Cara memeriksa
2 Sintaks usang gather(), spread(), size untuk garis (kini linewidth), rgdal Warning deprecated, dokumentasi
3 Metode populer tapi tak cocok ANOVA untuk hitungan, uji t berganda tanpa koreksi Tabel pemilihan uji Modul 4
4 Data diubah diam-diam na.omit(df) di awal skrip Jumlah baris sebelum/sesudah
5 Salah tafsir output Koefisien log dibaca selisih; p > 0,05 = “tidak ada beda” Tafsirkan sendiri dulu
6 Angka dikarang Nilai F dan p tanpa pernah melihat output Setiap angka dari output R
7 Sistem salah Path C:/ untuk pengguna Mac; pbpaste untuk Windows Sebutkan sistem di prompt

Video 7.4
Debugging dan reprex

Enam langkah debugging

  1. Baca pesan error sampai habis: fungsi dan objek apa yang disebut?
  2. Jalankan baris per baris sampai menemukan yang gagal
  3. Periksa masukannya: class(), str(), head()
  4. Baca halaman Help fungsi itu
  5. Belum selesai? Buat reprex
  6. Setelah diperbaiki, jalankan ulang seluruh skrip dari awal

reprex DEMO

install.packages("reprex")
# 1. Salin kode contoh minimal
# 2. Jalankan:
reprex::reprex()
# 3. Kode + hasil tersalin otomatis; tempel ke forum atau AI
Langkah Mac Windows
Salin kode Cmd+C Ctrl+C
Tempel hasil Cmd+V Ctrl+V

reprex gagal karena object not found? Contoh belum lengkap, dan itu petunjuk. Kirim error sebagai teks, bukan tangkapan layar.

Video 7.5
Mengaudit skrip

Daftar periksa audit

  1. Jalan dari awal setelah Restart R (Mac Cmd+Shift+0 · Windows Ctrl+Shift+F10), tanpa setwd() atau path lengkap
  2. Data masuk: jumlah baris dan tipe kolom sesuai
  3. Perubahan data: setiap filter, na.omit, distinct, join diperiksa jumlah barisnya
  4. Fungsi dan argumen ada di dokumentasi versi terpasang
  5. Metode sesuai tipe respons dan desain
  6. Asumsi diperiksa (sisaan atau DHARMa)
  7. Tafsiran: skala benar, perbandingan berganda dikoreksi, ukuran efek
  8. Grafik tidak membuang data; label dan satuan benar
  9. Angka di teks dapat ditelusuri ke output

Audit bersama: temukan minimal enam masalah

library(tidyverse)
data <- read.csv("C:/Users/Dewi/Downloads/survei.csv")
data <- na.omit(data)
data$zona <- as.factor(data$zona)
rata <- data %>%
  group_by(zona) %>%
  summarise(semai = mean(semai, remove_na = TRUE))
model <- aov(semai ~ zona, data = data)
summary(model)
TukeyHSD(model)
ggplot(rata, aes(zona, semai)) + geom_col() + ylim(0, 10)
# Hasil: zona berpengaruh nyata terhadap jumlah semai (F = 12,3; p < 0,001)

Desain: 8 stasiun × 6 plot, respons jumlah semai. Jeda video, cari sendiri.

Video 7.6
Batas penggunaan dan pernyataan AI

Kapan tidak memakai AI

  • Data memuat identitas, lokasi sensitif, atau data tanpa izin berbagi
  • Desain dan formula model belum Anda tentukan sendiri
  • Ujian atau kegiatan yang melarang AI
  • Anda tidak bisa memeriksa hasilnya: kode yang tidak bisa Anda jelaskan jangan dipakai

Asisten AI di editor (mis. GitHub Copilot di RStudio, lewat Tools → Global Options): setiap saran dibaca dan dipahami sebelum diterima.

Pernyataan penggunaan AI

Pernyataan penggunaan AI: Penulis menggunakan [nama alat dan versi] untuk
[membantu menulis dan menjelaskan kode R untuk pembersihan data dan pemodelan /
menyunting bahasa]. Seluruh kode diperiksa, dijalankan, dan diverifikasi oleh
penulis. Desain analisis, pemilihan model, dan tafsiran hasil ditentukan oleh
penulis. Penulis bertanggung jawab penuh atas isi naskah.
