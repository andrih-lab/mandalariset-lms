Video 5.2
GLM dan fungsi link

Data latihan: 8 stasiun × 6 plot

library(dplyr)
set.seed(1)
d <- expand.grid(stasiun = paste0("S", 1:8), plot = 1:6, stringsAsFactors = FALSE)
d$zona <- ifelse(d$plot <= 3, "depan", "belakang")
efek_stasiun <- setNames(rnorm(8, 0, 0.5), paste0("S", 1:8))
mu <- exp(1.5 + 0.6 * (d$zona == "belakang") + efek_stasiun[d$stasiun])
d$semai <- rnbinom(nrow(d), mu = mu, size = 1.5)
d <- d |> mutate(stasiun = factor(stasiun),
                 zona    = factor(zona, levels = c("depan", "belakang")),
                 luas_m2 = 25)

GLM Poisson

m_pois <- glm(semai ~ zona, family = poisson, data = d)
summary(m_pois)

Link log: model menghitung di skala log, prediksi tidak pernah negatif.

Koefisien 0,6 ≠ “0,6 semai lebih banyak”. Artinya exp(0,6) ≈ 1,8 kali zona depan.

GLM binomial

# Kelangsungan hidup bibit: jumlah hidup dan mati per petak
glm(cbind(hidup, mati) ~ perlakuan, family = binomial, data = bibit)

# Kehadiran spesies (1/0) terhadap salinitas
glm(hadir ~ salinitas, family = binomial, data = survei)

Link logit; exp(koefisien) = rasio odds.

Persentase hidup jangan dianalisis dengan ANOVA: petak 2 bibit dan 50 bibit dianggap sama informatifnya.

Video 5.3
Overdispersi dan binomial negatif

Memeriksa overdispersi

library(performance)
check_overdispersion(m_pois)   # rasio ≈ 1 aman; jauh > 1 = overdispersi

Poisson mengasumsikan ragam = rata-rata. Semai yang mengelompok membuat ragam jauh lebih besar.

Overdispersi diabaikan → galat baku terlalu kecil → nilai p terlalu kecil.

Binomial negatif

m_nb <- MASS::glm.nb(semai ~ zona, data = d)   # tanpa library(MASS)
AIC(m_pois, m_nb)                              # lebih kecil = lebih baik

library(MASS) menimpa dplyr::select(). Panggil dengan MASS::.

Video 5.4
Dari desain ke formula

Gambar desain dulu, sebelum menyentuh R.

Plot di dalam stasiun

S1 [● ● ●│● ● ●]   S2 [● ● ●│● ● ●]   ...   S8 [● ● ●│● ● ●]
     depan belakang

Plot dalam satu stasiun berbagi pasang surut, sedimen, riwayat gangguan → tidak independen.

semai ~ zona + (1 | stasiun)

Setiap stasiun boleh punya rata-rata sendiri.

Pola desain → formula

Desain Contoh Formula
Plot dalam stasiun 6 plot × 8 stasiun y ~ zona + (1 | stasiun)
Bersarang dua tingkat Stasiun dalam desa y ~ x + (1 | desa/stasiun)
Pengukuran berulang Tinggi bibit tiap minggu y ~ minggu * perlakuan + (1 | id_bibit)
Rancangan acak kelompok 4 blok, 3 perlakuan y ~ perlakuan + (1 | blok)
Perlakuan di tingkat stasiun Rehabilitasi vs alami y ~ kelola + (1 | stasiun)
Luas sampling berbeda Plot 25 dan 100 m² + offset(log(luas_m2))

Efek acak dengan < ±5 taraf sulit diduga → pertimbangkan efek tetap.

Pseudoreplikasi

4 stasiun rehabilitasi, 4 stasiun alami, 6 plot per stasiun.

Status pengelolaan melekat pada stasiun. Ulangan = 8 stasiun, bukan 48 plot.

glmmTMB(semai ~ kelola + (1 | stasiun), family = nbinom2, data = d)

Video 5.5
Model campuran dengan glmmTMB dan lme4

glmmTMB

library(glmmTMB)
m_mix <- glmmTMB(semai ~ zona + (1 | stasiun), family = nbinom2, data = d)
summary(m_mix)   # Random effects: ragam antarstasiun
                 # Conditional model: efek tetap (skala log)

m_off <- glmmTMB(semai ~ zona + offset(log(luas_m2)) + (1 | stasiun),
                 family = nbinom2, data = d)            # kepadatan per m²

lme4 dan peringatan

library(lmerTest)   # memuat lme4, menambah nilai p
m_tinggi <- lmer(tinggi_cm ~ minggu * perlakuan + (1 | id_bibit), data = bibit)
anova(m_tinggi)

non-positive-definite Hessian (glmmTMB) atau boundary (singular) fit (lme4): jangan diabaikan. Sederhanakan efek acak, periksa kelompok dengan data sedikit, catat keputusan.

Menafsirkan dan melaporkan

Kembali ke skala asli

library(emmeans)
emmeans(m_mix, ~ zona, type = "response")            # semai per plot + IK 95%
emmeans(m_mix, pairwise ~ zona, type = "response")   # rasio belakang/depan
packageVersion("glmmTMB")                            # untuk bagian metode

Jumlah semai per plot dianalisis dengan model linear campuran tergeneralisasi sebaran binomial negatif (link log), zona sebagai efek tetap dan stasiun sebagai efek acak, dengan glmmTMB [versi] di R [versi]. Kesesuaian model diperiksa dengan DHARMa.
