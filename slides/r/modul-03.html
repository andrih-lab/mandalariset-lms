Video 3.1
Tata bahasa grafik

Dua tujuan: grafik untuk memeriksa data dan grafik untuk pembaca naskah.

Lapisan ggplot2

Lapisan Mengatur Contoh
Data Tabel veg
Estetika aes() Kolom → sumbu, warna, bentuk x = dbh_cm, y = tinggi_m
Geom Bentuk tampilan geom_point(), geom_boxplot()
Skala Sumbu dan warna scale_colour_manual()
Facet Panel per kelompok facet_wrap(~ stasiun)
Tema Tampilan umum theme_classic()

Grafik pertama

library(ggplot2)
library(dplyr)
library(readr)
library(here)

veg <- read_csv(here("data", "vegetasi_bersih.csv")) |>
  mutate(zona = factor(zona, levels = c("depan", "tengah", "belakang")))

ggplot(data = veg, aes(x = dbh_cm, y = tinggi_m)) +
  geom_point()

Tanpa factor(levels = ...), zona diurutkan menurut abjad: belakang, depan, tengah.

Video 3.2
Grafik untuk memeriksa data

Sebaran dan perbandingan kelompok

# Sebaran satu variabel: cari kemiringan dan salah ketik
ggplot(veg, aes(x = dbh_cm)) +
  geom_histogram(binwidth = 2)

# Kelompok: kotak + semua titik data
ggplot(veg, aes(x = zona, y = dbh_cm)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.4)

Hubungan dan panel per stasiun

ggplot(veg, aes(x = dbh_cm, y = tinggi_m, colour = spesies)) +
  geom_point(alpha = 0.6) +
  geom_smooth(method = "lm", formula = y ~ x, se = TRUE)

ggplot(veg, aes(x = dbh_cm)) +
  geom_histogram(binwidth = 2) +
  facet_wrap(~ stasiun, scales = "free_y")

Catat temuan dari setiap grafik: dipakai lagi saat memilih model.

Memilih grafik yang tepat

Batang rata-rata menyembunyikan data

Dua kelompok tampak berbeda pada grafik batang ± galat. Data aslinya: satu kelompok hanya 5 titik, dua di antaranya pencilan.

Tampilkan data, bukan hanya ringkasan.

Pertanyaan menentukan grafik

Pertanyaan Disarankan Hindari
Sebaran satu variabel Histogram, density Tabel angka saja
Kelompok, data kontinu Titik + rata-rata ± SE, boxplot + titik Batang rata-rata tanpa sebaran
Hubungan dua variabel Titik + garis regresi Garis antartitik tak berurutan
Perubahan menurut waktu Garis dengan titik Batang bertumpuk sulit dibaca
Komposisi Batang bertumpuk 100% Pie dengan banyak irisan
Jumlah per kategori Batang dari nol Sumbu y tidak mulai dari nol

Video 3.4
Grafik publikasi

Perbandingan zona, siap terbit

p1 <- ggplot(veg, aes(x = zona, y = dbh_cm)) +
  geom_jitter(width = 0.15, alpha = 0.25, colour = "grey40") +
  stat_summary(fun.data = mean_se, colour = "black", size = 0.6) +
  labs(x = "Zona", y = "Diameter setinggi dada (cm)") +
  theme_classic(base_size = 11, base_family = "Arial")

Font Arial tersedia di Mac dan Windows: grafik sama di kedua sistem.

Warna ramah buta warna, nama spesies miring

warna <- unname(palette.colors(palette = "Okabe-Ito")[-1])

p2 <- ggplot(veg, aes(x = dbh_cm, y = tinggi_m, colour = spesies)) +
  geom_point(alpha = 0.6) +
  geom_smooth(method = "lm", formula = y ~ x, se = FALSE) +
  scale_colour_manual(values = warna) +
  labs(x = "Diameter setinggi dada (cm)", y = "Tinggi (m)", colour = "Spesies") +
  theme_classic(base_size = 11, base_family = "Arial") +
  theme(legend.text = element_text(face = "italic"))

library(patchwork)

(p1 | p2) + plot_annotation(tag_levels = "A")   # berdampingan, label A dan B

(p1 | p2) / p3                                  # dua di atas, satu di bawah

Video 3.6
Ekspor di Mac dan Windows

Ekspor dengan ragg

library(ragg)
panel <- (p1 | p2) + plot_annotation(tag_levels = "A")

ggsave(here("output", "gambar1.png"), panel, device = ragg::agg_png,
       width = 17, height = 8, units = "cm", dpi = 300)

ggsave(here("output", "gambar1.tiff"), panel, device = ragg::agg_tiff,
       width = 17, height = 8, units = "cm", dpi = 600, compression = "lzw")

Lebar kolom jurnal: ±8–9 cm (satu kolom), ±17–18 cm (halaman). Cek pedoman penulis.

RStudio: Tools → Global Options → General → Graphics → Backend AGG

Memeriksa hasil ekspor

Mac

Buka di Preview → Tools → Show Inspector (Cmd+I)

PDF: cairo_pdf; bila error cairo/X11, pasang XQuartz

Windows

Klik kanan → Properties → Details

PDF: cairo_pdf biasanya langsung berjalan

17 cm pada 300 dpi ≈ 2008 piksel lebar (17 ÷ 2,54 × 300).
