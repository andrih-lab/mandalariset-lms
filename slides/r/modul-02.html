Video 2.2
Mengekspor CSV dari Excel di Mac

Excel for Mac → CSV UTF-8

  1. File → Save As
  2. File Format: CSV UTF-8 (Comma delimited) (.csv)
  3. Simpan ke folder data-raw/ proyek

Periksa isi file: RStudio panel Files → klik file → View File (atau Finder: klik kanan → Open With → TextEdit)

Baris pertama berisi Artinya
Plot,Stasiun,DBH (cm) dan 12.5 Pemisah koma, desimal titik
Plot;Stasiun;DBH (cm) dan 12,5 Pemisah titik koma, desimal koma

Video 2.3
Mengekspor CSV dari Excel di Windows

Excel di Windows → CSV UTF-8

  1. File → Save As → Browse
  2. Save as type: CSV UTF-8 (Comma delimited) (*.csv)
  3. Simpan ke folder data-raw/

Pengaturan wilayah: Settings → Time & Language → Language & region; pemisah daftar di Control Panel → Region → Additional settings

Periksa isi: View File di RStudio, atau klik kanan → Open with → Notepad

File masih terbuka di Excel? R bisa gagal membaca. Tutup dulu.

Video 2.5
Lima fungsi dplyr

Memilih, membuat, mengurutkan

library(dplyr)

veg |> filter(dbh_cm >= 5)                     # memilih baris
veg |> select(plot, spesies, dbh_cm)           # memilih kolom
veg |> mutate(ba_m2 = pi * (dbh_cm / 200)^2)   # kolom baru: luas bidang dasar (m²)
veg |> arrange(desc(dbh_cm))                   # mengurutkan

Luas bidang dasar = π × (D/2)², D dalam meter → dbh_cm / 200

Ringkasan per kelompok

veg |>
  mutate(ba_m2 = pi * (dbh_cm / 200)^2) |>
  group_by(stasiun, spesies) |>
  summarise(n           = n(),
            dbh_rerata  = mean(dbh_cm, na.rm = TRUE),
            ba_total_m2 = sum(ba_m2, na.rm = TRUE),
            .groups = "drop")

veg |> count(spesies, sort = TRUE)   # cepat memeriksa ejaan spesies

library(stringr)
veg <- veg |> mutate(spesies = str_to_sentence(str_squish(spesies)))
veg |> distinct(spesies)

Video 2.9
Pemeriksaan dan menyimpan hasil

Fungsi cek() di setiap langkah

cek <- function(df, label) {
  message(label, ": ", nrow(df), " baris, ",
          sum(duplicated(df)), " duplikat, ",
          sum(is.na(df)), " sel NA")
  invisible(df)
}

veg_bersih <- veg |>
  cek("awal") |>
  distinct() |>
  cek("setelah hapus duplikat") |>
  filter(!is.na(dbh_cm)) |>          # alasan: DBH wajib untuk analisis
  cek("setelah buang DBH kosong")

Menyimpan hasil

write_csv(veg_bersih, here("data", "vegetasi_bersih.csv"))
write_excel_csv2(veg_bersih, here("data", "vegetasi_untuk_excel.csv"))
  • write_excel_csv2(): titik koma, desimal koma, UTF-8. Rapi di Excel Mac dan Windows.
  • File di data-raw/ tidak pernah ditimpa.
