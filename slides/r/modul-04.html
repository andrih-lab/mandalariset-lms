Video 4.1
Dari pertanyaan ke uji

“Uji apa yang cocok untuk data saya?”

Tiga informasi yang harus Anda tulis, dan juga yang harus Anda berikan ke AI:

  1. Variabel respons dan tipenya: kontinu, hitungan, proporsi, kategori
  2. Prediktor dan tipenya: faktor atau kontinu
  3. Independensi: apakah pengamatan saling bebas? (plot dalam stasiun: tidak)

Data latihan

library(dplyr)
library(ggplot2)

set.seed(42)
dat <- tibble(
  zona      = factor(rep(c("depan", "tengah", "belakang"), each = 20),
                     levels = c("depan", "tengah", "belakang")),
  salinitas = c(rnorm(20, 30, 2), rnorm(20, 25, 2), rnorm(20, 20, 2)),
  dbh_cm    = c(rnorm(20, 12, 3), rnorm(20, 15, 3), rnorm(20, 18, 3))
)

set.seed() → angka yang sama di Mac dan Windows, selama versi R sama.

Video 4.2
Membandingkan dua kelompok

Uji t Welch

dua <- dat |> filter(zona != "belakang") |> droplevels()

t.test(dbh_cm ~ zona, data = dua)        # Welch: ragam tidak harus sama

Baca: nilai t, derajat bebas, nilai p, dan selang kepercayaan 95% selisih rata-rata.

~ dibaca “menurut” atau “dijelaskan oleh”.

Alternatif dan ukuran efek

wilcox.test(dbh_cm ~ zona, data = dua)   # sebaran sangat miring, sampel kecil

library(effectsize)
cohens_d(dbh_cm ~ zona, data = dua)      # besar perbedaan dalam satuan SD

Video 4.3
Membandingkan lebih dari dua kelompok

ANOVA dengan lm()

m1 <- lm(dbh_cm ~ zona, data = dat)
anova(m1)
#>           Df ...
#> zona       2 ...     <- 3 kelompok = 2 derajat bebas

lm() adalah dasar regresi, GLM, dan model campuran di Modul 5.

Cek derajat bebas: Df = 1 untuk faktor 3 taraf berarti variabelnya terbaca sebagai angka.

Perbandingan berpasangan dan ukuran efek

library(emmeans)
emmeans(m1, pairwise ~ zona)       # rata-rata + perbandingan (koreksi Tukey)

library(effectsize)
eta_squared(m1)                    # proporsi ragam yang dijelaskan zona

kruskal.test(dbh_cm ~ zona, data = dat)   # alternatif nonparametrik

Video 4.5
Korelasi dan regresi linear

Korelasi dan regresi

cor.test(~ dbh_cm + salinitas, data = dat, method = "pearson")
cor.test(~ dbh_cm + salinitas, data = dat, method = "spearman")

m2 <- lm(dbh_cm ~ salinitas, data = dat)
summary(m2)      # koefisien salinitas: perubahan DBH (cm) per 1 ppt
confint(m2)      # selang kepercayaan 95%
r2(m2)           # paket performance
check_model(m2)

Selalu lihat grafiknya

ggplot(dat, aes(salinitas, dbh_cm)) +
  geom_point() +
  geom_smooth(method = "lm", formula = y ~ x)

Data pengamatan: tulis “berhubungan dengan”, bukan “menyebabkan”.

Data kategori

Khi-kuadrat dan Fisher

tabel <- matrix(c(12, 8, 5, 15), nrow = 2,
                dimnames = list(kepiting = c("ada", "tidak"),
                                zona     = c("depan", "belakang")))
chisq.test(tabel)
chisq.test(tabel)$expected   # frekuensi harapan
fisher.test(tabel)           # bila ada frekuensi harapan < 5

Kehadiran terhadap variabel kontinu (misal salinitas) → regresi logistik, Modul 5.

Video 4.7
Melaporkan hasil

Perbandingan berganda

p_mentah <- c(0.012, 0.041, 0.030)
p.adjust(p_mentah, method = "holm")

Banyak uji → peluang positif palsu naik. emmeans sudah mengoreksi otomatis; uji terpisah dikoreksi dengan p.adjust().

Kalimat hasil yang lengkap

DBH berbeda antarzona (F(2, 57) = …; p < 0,001; η² = …). Rata-rata DBH di zona belakang … cm lebih besar daripada zona depan (IK 95%: …–… cm; p < 0,001, koreksi Tukey).

Wajib: statistik uji + derajat bebas, nilai p, ukuran efek, selang kepercayaan.

Semua angka disalin dari output R. Jangan minta AI menulis hasil tanpa memberikan output.

p besar ≠ tidak ada perbedaan

“p = 0,21, jadi tidak ada perbedaan salinitas antarstasiun.” Salah.

  • Artinya: data belum cukup menunjukkan perbedaan
  • Laporkan selang kepercayaan; lebar = ketidakpastian besar
