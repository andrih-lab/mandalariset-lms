Video 8.5
renv: mencatat versi paket

renv

install.packages("renv")
renv::init()       # sekali per proyek: renv.lock + pustaka khusus proyek
renv::snapshot()   # setelah memasang/memperbarui paket
renv::status()     # ada paket yang belum tercatat?
renv::restore()    # di komputer lain: pasang sesuai renv.lock

renv.lock berlaku lintas sistem: dibuat di Mac, dipulihkan di Windows, dan sebaliknya.

Versi lama tanpa biner → dikompilasi: Mac Command Line Tools · Windows Rtools

Video 8.7
Memasang Git di Windows

Git di Windows

  1. git-scm.com → Git for Windows, pilihan bawaan (termasuk Git Bash dan Git Credential Manager)
  2. Tutup dan buka lagi RStudio
  3. Tools → Global Options → Git/SVN → C:/Program Files/Git/bin/git.exe
  4. Opsional: Terminal → Git Bash sebagai terminal bawaan

Akhir baris Windows (CRLF) ≠ Mac (LF) → diatur dengan .gitattributes (video 8.8)

Video 8.8
Git dan GitHub dari RStudio

Menghubungkan ke GitHub

install.packages(c("usethis", "gitcreds"))
usethis::use_git_config(user.name = "Nama Anda", user.email = "email@kampus.ac.id")
usethis::use_git()               # jadikan repositori Git; restart RStudio
usethis::create_github_token()   # buat token di GitHub
gitcreds::gitcreds_set()         # tempel token
usethis::use_github(private = TRUE)

Video 8.9
Arsip dan pernyataan

DOI untuk kode dan data

  • Zenodo: hubungkan GitHub → aktifkan repositori → buat release → dapat DOI
  • OSF: unggah folder proyek (tanpa data sensitif) → buat DOI
  • Data sensitif: bagikan versi teranonimkan/agregat, atau jelaskan prosedur permintaan
Seluruh analisis dilakukan di R [versi]. Jumlah semai dianalisis dengan [model]
menggunakan glmmTMB [versi]; kesesuaian model diperiksa dengan DHARMa [versi].
Versi seluruh paket dicatat dengan renv. Kode dan data tersedia di [DOI].
R.version.string; packageVersion("glmmTMB")   # jangan diketik dari ingatan

Uji ulang lintas sistem

Pasangan: sebisa mungkin Mac + Windows

  1. Buka .Rproj proyek teman
  2. renv::restore()
  3. Render laporan.qmd
  4. Catat setiap error dan perbedaan (angka, grafik, font)

Mac dan Windows tidak membedakan huruf besar-kecil nama file; Linux (Posit Cloud, server) membedakannya. vegetasi.csv ≠ Vegetasi.csv.
