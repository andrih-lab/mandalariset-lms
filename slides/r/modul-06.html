Jalur A
Ekologi komunitas

vegan: keanekaragaman, akumulasi spesies, NMDS, PERMANOVA

6A.1 Dari data lapangan ke matriks komunitas

library(dplyr)
library(tidyr)
library(vegan)

komunitas <- veg |>
  count(plot, spesies) |>
  pivot_wider(names_from = spesies, values_from = n, values_fill = 0) |>
  tibble::column_to_rownames("plot")

Periksa nama spesies dengan distinct() dulu: satu salah ketik = satu “spesies baru”.

6A.2 Keanekaragaman dan kurva akumulasi

data(dune); data(dune.env)

H <- diversity(dune, index = "shannon")
S <- specnumber(dune)
J <- H / log(S)                                   # kemerataan Pielou

sac <- specaccum(dune, method = "random", permutations = 100)
plot(sac, ci.type = "poly", ci.col = "grey85", ci.lty = 0)

Kurva masih naik di ujung → masih ada spesies yang belum tercatat.

6A.3 NMDS dan nilai stress

set.seed(1)
nmds <- metaMDS(dune, distance = "bray", k = 2, trymax = 100)
nmds$stress
stressplot(nmds)
Stress Tafsiran
< 0,1 Baik
0,1–0,2 Tafsirkan dengan hati-hati
> 0,2 Sebaiknya tidak ditafsirkan

6A.4 PERMANOVA dan uji dispersi

set.seed(1)
adonis2(dune ~ Management, data = dune.env, permutations = 999, method = "bray")

bd <- betadisper(vegdist(dune, method = "bray"), dune.env$Management)
permutest(bd, permutations = 999)
PERMANOVA betadisper Kesimpulan
Nyata Tidak nyata Komposisi berbeda
Nyata Nyata Bisa karena sebaran berbeda: laporkan keduanya

6A.5 Grafik ordinasi

library(ggplot2)
sc <- as.data.frame(scores(nmds, display = "sites"))
sc$Management <- dune.env$Management

ggplot(sc, aes(NMDS1, NMDS2, colour = Management)) +
  geom_point(size = 3) +
  stat_ellipse(level = 0.95) +
  coord_equal() +                       # kedua sumbu berskala sama
  theme_classic(base_family = "Arial")

Tugas jalur A: matriks komunitas, indeks, NMDS + stress, PERMANOVA + betadisper.

Jalur B
Spasial

sf untuk vektor, terra untuk raster

6B.1 Vektor, raster, sistem koordinat

Jenis Contoh Paket
Vektor Titik plot, garis pantai, batas desa sf
Raster Citra satelit, NDVI, ketinggian terra
Sistem Satuan Contoh
WGS84 (EPSG 4326) Derajat Koordinat GPS
UTM 47N (32647) / 48N (32648) Meter Jarak, luas, buffer

sf dan terra: biner CRAN di Mac dan Windows, tanpa GDAL terpisah.

6B.2 Titik plot dari koordinat GPS

library(sf); library(readr); library(ggplot2); library(here)

plot_pt <- read_csv(here("data-raw", "plot.csv")) |>
  st_as_sf(coords = c("lon", "lat"), crs = 4326)   # bujur dulu, lalu lintang

ggplot() + geom_sf(data = plot_pt)                 # petakan segera

batas <- st_read(here("data-raw", "batas_desa.gpkg"))
st_crs(batas)

Zip dari Mac berisi __MACOSX dan .DS_Store? Pengguna Windows abaikan saja. Untuk berbagi, pakai GeoPackage (satu file).

6B.3 Transformasi, buffer, jarak

batas_utm <- st_transform(batas, 32647)     # sesuaikan zona UTM
plot_utm  <- st_transform(plot_pt, 32647)

buffer_100 <- st_buffer(plot_utm, dist = 100)   # 100 meter
st_distance(plot_utm, garis_pantai_utm)          # jarak ke garis pantai
st_area(batas_utm)

Buffer pada data berderajat (EPSG 4326) tidak dalam meter. Ubah ke UTM dulu.

6B.4 Raster dan ekstraksi nilai

library(terra)
r <- rast(here("data-raw", "ndvi.tif"))
crs(r, describe = TRUE)

titik_r <- project(vect(plot_pt), crs(r))   # samakan sistem koordinat
nilai   <- terra::extract(r, titik_r)
plot_pt$ndvi <- nilai[, 2]

Semua hasil NA? Periksa sistem koordinat dan urutan bujur–lintang.

6B.5 Peta publikasi

ggplot() +
  geom_sf(data = batas_utm, fill = "grey95") +
  geom_sf(data = plot_utm, aes(colour = zona), size = 2) +
  theme_minimal(base_family = "Arial")

st_write(plot_utm, here("output", "plot_utm.gpkg"), delete_dsn = TRUE)

Skala dan arah utara: paket ggspatial. Sunting manual: QGIS (Mac dan Windows).

Tugas jalur B: titik plot, satu operasi vektor, ekstraksi raster, satu peta publikasi.

Jalur C
Kuesioner dan sosial

psych dan lavaan

6C.1 Anonimisasi dan pemeriksaan

kues <- read_csv(here("data-raw", "kuesioner.csv")) |> janitor::clean_names()
kues <- kues |> select(-nama, -no_hp)       # sebelum analisis dan sebelum ke AI
glimpse(kues)
kues |> count(q1)                           # nilai di luar skala 1–5?

CSV UTF-8 dari Google Forms/KoboToolbox terbaca benar oleh read_csv() di kedua sistem. Huruf rusak saat dibuka di Excel Windows = masalah tampilan Excel.

6C.2 Grafik Likert

library(tidyr); library(ggplot2)
kues |>
  pivot_longer(q1:q8, names_to = "butir", values_to = "skor") |>
  ggplot(aes(y = butir, fill = factor(skor))) +
  geom_bar(position = "fill") +
  labs(x = "Proporsi", y = NULL, fill = "Skor") +
  theme_minimal(base_family = "Arial")

6C.3 Butir negatif dan reliabilitas

kues <- kues |> mutate(across(c(q3, q7), \(x) 6 - x))   # skala 1–5

library(psych)
psych::alpha(select(kues, q1:q4))    # per dimensi, bukan seluruh kuesioner

Alpha rendah + peringatan korelasi negatif = butir negatif belum dibalik.

6C.4 Analisis faktor eksploratori

fa.parallel(select(kues, q1:q8), fa = "fa")                 # saran jumlah faktor
fa(select(kues, q1:q8), nfactors = 2, rotate = "oblimin",   # perlu GPArotation
   fm = "minres")

Setiap butir sebaiknya bermuatan tinggi pada satu faktor. Muatan rendah di semua faktor, atau tinggi di dua faktor → tinjau ulang butir.

6C.5 Pengantar CFA dengan lavaan

library(lavaan)
model <- '
  pengetahuan =~ q1 + q2 + q3 + q4
  sikap       =~ q5 + q6 + q7 + q8
'
fit <- cfa(model, data = kues, ordered = TRUE)   # Likert = data berurutan
summary(fit, fit.measures = TRUE, standardized = TRUE)

Baca CFI, TLI, RMSEA, dan muatan terstandar. Sebutkan sumber nilai ambang di naskah.

Tugas jalur C: data teranonimkan, grafik Likert, reliabilitas per dimensi, analisis faktor.

Jalur D
Bibliometrik

bibliometrix

6D.1 Ekspor dari Scopus dan Web of Science

Basis data Format ekspor
Scopus CSV, semua informasi (abstrak, kata kunci, referensi)
Web of Science Plain text, Full Record and Cited References; hasil besar dalam beberapa file

Simpan string pencarian dan tanggal pencarian.

Mac ~/Downloads → pindahkan ke data-raw/

Windows C:/Users/nama/Downloads → pindahkan ke data-raw/

6D.2 Mengimpor dan menggabungkan

library(bibliometrix); library(here)

M_scopus <- convert2df(here("data-raw", "scopus.csv"), dbsource = "scopus", format = "csv")
M_wos    <- convert2df(c(here("data-raw", "wos_1.txt"), here("data-raw", "wos_2.txt")),
                       dbsource = "wos", format = "plaintext")

M <- mergeDbSources(M_scopus, M_wos, remove.duplicated = TRUE)
nrow(M_scopus); nrow(M_wos); nrow(M)   # untuk PRISMA / bagian metode

6D.3 Analisis deskriptif

hasil <- biblioAnalysis(M, sep = ";")
summary(hasil, k = 10, pause = FALSE)
plot(hasil, k = 10, pause = FALSE)

Tahun berjalan selalu tampak turun karena data belum lengkap. Tandai atau keluarkan dari grafik tren.

6D.4 Jaringan kata kunci

net <- biblioNetwork(M, analysis = "co-occurrences", network = "keywords", sep = ";")
networkPlot(net, n = 30, type = "fruchterman",
            Title = "Ko-okurensi kata kunci", size = TRUE, labelsize = 0.7)

“mangrove” dan “mangroves” jadi dua simpul? Satukan bentuk jamak, singkatan, dan sinonim sebelum analisis.

6D.5 biblioshiny dan pelaporan

biblioshiny()   # terbuka di browser bawaan
  • Bagus untuk eksplorasi cepat
  • Hasil akhir untuk naskah dibuat dari skrip: klik di biblioshiny tidak tercatat

Tugas jalur D: data gabungan + jumlah duplikat, analisis deskriptif, jaringan kata kunci setelah sinonim disatukan.
